# Hackathon Strategy

## Objective

Build the strongest possible implementation of HeatShift using FortyGuard temperature intelligence.

## What We Want Judges To Remember

"These people turned temperature data into an economically valuable infrastructure decision."

## Judging Strategy

Whatever the final official judging criteria are, optimize the project around:

- originality
- usefulness
- technical credibility
- commercial potential
- FortyGuard integration
- feasibility
- visual demonstration
- working prototype

## Rule

Official hackathon documentation overrides assumptions in this repository.

When exact judging criteria or technical rules are confirmed, update this file.

## Core Competitive Advantage

Do not merely visualize FortyGuard data.

Use the data as an input into an optimization decision whose output has a measurable economic consequence.

## Demo Standard

A judge should understand:

Problem → FortyGuard → Decision → Dollar Impact

within roughly 30 seconds.
